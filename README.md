# Personal Portfolio Website

This is a simple **personal portfolio website** built using **HTML and CSS**. The project contains two main pages: **Home** and **Contact**. It is designed to showcase personal information, projects, and provide a way for visitors to get in touch.

## 📌 Features

* Responsive and clean design
* Home page with introduction and portfolio details
* Contact page for users to reach out
* Simple navigation between pages
* Built using only HTML and CSS

## 🛠️ Technologies Used

* **HTML5** – for structuring the website
* **CSS3** – for styling and layout

## 📂 Project Structure

```
portfolio-website/
│
├── index.html        # Home page
├── contact.html      # Contact page
├── style.css         # Main stylesheet
└── README.md         # Project documentation
```

## 🚀 Getting Started

To run this project locally:

1. Download or clone the repository
2. Open the project folder
3. Open `index.html` in your browser

Example:

```bash
git clone https://github.com/your-username/portfolio-website.git
```

Then open **index.html** in any browser.

## 📄 Pages

### Home

The home page introduces the portfolio owner and displays basic information such as skills, projects, or a short bio.

### Contact

The contact page allows visitors to reach out through a contact form or contact information.

## 🎯 Purpose of the Project

This project was created to practice **basic web development skills** and learn how to build a simple multi-page website using HTML and CSS.
